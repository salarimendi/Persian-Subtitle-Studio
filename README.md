# زیرنویس فارسی محلی

تبدیل گفتار ویدیو به زیرنویس فارسی (faster-whisper روی CPU) و چسباندن آن به تصویر با FFmpeg. همه‌چیز محلی است.

## مدل تشخیص گفتار
- پیش‌فرض: **`oi-uae/farsi-faster-whisper-large-v3`**؛ تبدیل CTranslate2 (float16) از یک فاین‌تیون whisper-large-v3 روی Common Voice 17 فارسی. طبق صفحهٔ مدل، WER روی تست Common Voice 17 فارسی حدود ۲۳٫۵٪ گزارش شده است.
- دانلود: حدود **۳ گیگابایت**، هنگام اولین تبدیل (نه هنگام `pip install`). مسیر ذخیره: `models/farsi-faster-whisper-large-v3/`. بعد از آن بدون اینترنت و بدون دانلود مجدد.
- حافظه و سرعت: با `int8` روی CPU حدود ۳ گیگابایت RAM لازم است و بسیار کندتر از مدل `small` اجرا می‌شود.
- تنظیمات (متغیر محیطی، اختیاری): `SUBTITLE_MODEL` (مدل CT2 دیگر، مثلاً `Systran/faster-whisper-large-v3`)، `SUBTITLE_COMPUTE` (`int8` پیش‌فرض یا `float32`)، `SUBTITLE_THREADS`.
- روش رمزگشایی: زبان `fa`، beam=5، `condition_on_previous_text=False`، فیلتر VAD و temperature fallback. تنها اصلاح خودکار متن، یکسان‌سازی املایی بی‌خطر است (ي/ك عربی، ارقام عربی، فاصلهٔ اضافه)؛ هیچ واژه‌ای حدس زده یا جایگزین نمی‌شود. بخش‌هایی با تکرار غیرعادی یک کلمه فقط هشدار می‌گیرند.

## نصب و اجرا
با محیط مجازی مشترک در یک شاخه بالاتر:
```
cd D:\Projects
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r subtitle-app\requirements.txt
cd subtitle-app
..\.venv\Scripts\python main.py
```
سپس `http://127.0.0.1:8000` را باز کنید. FFmpeg لازم است: `winget install Gyan.FFmpeg`. (`start.bat` همین کار را خودکار انجام می‌دهد و اگر `..\.venv` باشد از آن استفاده می‌کند.)

## امکانات و استفاده
- **تایپوگرافی:** فونت (فهرست + فونت‌های پوشهٔ `fonts/`)، اندازه، ضخامت، رنگ، حاشیه، سایه، فاصلهٔ خطوط، محل و فاصله از لبه. اندازه نسبت به ابعاد تصویر مقیاس می‌شود و خط‌های عریض‌تر از تصویر خودکار کوچک می‌شوند.
- **پیش‌نمایش:** هنگام توقف یا جابه‌جایی، فریم واقعی ویدیو با همان ASS و همان libass خروجی نهایی نشان داده می‌شود (نه تقریب). هنگام پخش، نمایش تقریبی مرورگر است.
- **نگارش فارسی:** راست‌چین خودکار، اتصال حروف، ارقام (همان‌طور که هست / فارسی / انگلیسی)، اصلاح `?` `,` `;` به `؟` `،` `؛` و ترکیب فارسی و لاتین.
- **شکست جمله و زمان‌بندی:** حداکثر کاراکتر/کلمهٔ هر خط، حداکثر دو خط (متن بلندتر به چند زیرنویس تقسیم می‌شود)، حداقل مدت نمایش و فاصله بین زیرنویس‌ها (بدون هم‌پوشانی).
- **پس‌زمینه:** کادر گوشه‌گرد با رنگ، شفافیت، حاشیه و فاصلهٔ داخلی؛ عرض هر کادر با خود libass اندازه‌گیری می‌شود و کادر خط‌ها روی هم نمی‌افتند.
- **افکت کلمه‌ای:** رنگ کلمهٔ فعال، رنگ نرم، پرشدن تدریجی (کاراوکه) و رنگ + بزرگ‌شدن، هماهنگ با زمان هر کلمه. کلمهٔ تأکیدی و افکت ورود/خروج هر بخش مثل قبل هستند.
- **قالب‌های آماده:** سینمایی، مستند، شبکه‌های اجتماعی، مینیمال روشن، کاراوکه.
- **کاور:** تصویر کاور، مدت نمایش در ابتدای ویدیو، تعبیه Artwork در MP4 و فایل `_thumb.jpg`. اگر کاور شروع فعال باشد SRT/ASS به‌اندازهٔ همان مدت جابه‌جا می‌شوند.
- **چیدمان خروجی:** همان اندازهٔ ویدیو، عمودی ۹:۱۶، مربع ۱:۱ یا افقی ۱۶:۹ (برش مرکزی). فرمت‌ها را جدا انتخاب کنید: MP4، SRT، ASS.
- **پروژه‌ها:** با «ذخیرهٔ پروژه» یا هر خروجی، فایل‌های `نام.project.json` (متن، زمان، زمان کلمه‌ها، استایل، تنظیمات، کاور)، `نام.txt` و `نام.srt` در `output/` ذخیره می‌شوند. «باز کردن پروژهٔ قبلی» ویدیو را همراه با پروژهٔ ذخیره‌شده یا فایل `.json`، `.srt`، `.ass` (فایل ASS خود برنامه شامل پروژه است) یا `.txt` دوباره باز می‌کند، بدون رونویسی مجدد. فایل‌های قبلی فقط با تیک و تأیید شما بازنویسی می‌شوند؛ در غیر این صورت نام تازه استفاده می‌شود. ویدیوی اصلی هرگز تغییر نمی‌کند.

## مقایسهٔ دقت روی فایل خودتان
```
..\.venv\Scripts\python tests\compare_models.py نمونه.mp4 --ref متن_درست.txt
```
مدل قبلی (`small`) و مدل فعلی را روی همان فایل اجرا می‌کند و زمان، WER و CER را چاپ می‌کند. بدون `--ref` فقط زمان و متن چاپ می‌شود. برای نتیجهٔ معتبر، فایلی با گفتار واقعی خودتان و متن مرجع دستی استفاده کنید.

## آزمون
```
..\.venv\Scripts\python -m unittest discover -s tests -v
```
آزمون مدل و آزمون فارسی (`SAMPLE_AUDIO`، اختیاری `SAMPLE_REFERENCE`) اگر پیش‌نیازشان نباشد SKIP می‌شوند و هرگز مدل را دانلود نمی‌کنند.

## ساختار
`main.py` (API)، `core.py` (صف، FFmpeg، کاور، پروژه)، `subs.py` (استایل، چیدمان، ASS/SRT/TXT)، `asr.py` (مدل، رونویسی، WER)، `static/`، `tests/`، `models/`، `fonts/`، `output/`.

## محدودیت‌ها
ایموجی در MP4 ممکن است تک‌رنگ باشد (libass). فونت پیش‌فرض Tahoma است؛ برای Vazirmatn فایل `.ttf` را در `fonts/` بگذارید. نمایش تامنیل در Windows Explorer روی ویندوز بررسی نشده است.
